# 井与网格配套演示数据

全部数据由数学函数生成，不包含真实油田资料。适合测试导入、属性着色、网格过滤、拾取、井轨迹显示和工程保存；没有流体、边界、完井或生产制度配置，不能直接作为数值模拟算例运行。

## 内容

| 文件 | 内容 |
| --- | --- |
| `SYNTHETIC.GRDECL` | 50 × 40 × 20 角点网格，共 40,000 单元，39,520 个活动单元 |
| `Wellheader.txt` | 6 口井的井名、井口坐标、KB 和总测深 |
| `wells/*.dev` | 每井 121 个轨迹点，包含 MD、X、Y、Z、TVD、DX、DY、AZIM、INCL |
| `manifest.json` | 维度、活动单元数、单位及逐井轨迹统计 |

网格平面范围：X = 500000～502000 m，Y = 3300000～3301600 m；平面单元 40 × 40 m，20 层，每层厚 10 m。顶面埋深约 1700～1766 m，带平滑起伏。两个角部设置非活动单元。内嵌 PORO、PERMX、PERMY、PERMZ、SATNUM 五项属性，其中渗透率用 mD、孔隙度用小数，分区编号为 1～3。属性沿弯曲高渗通道和层位变化，便于观察着色与过滤。

包含两口直井（PROD_V1、INJ_V1）、两口斜井（PROD_D1、INJ_D1）和两口水平井（PROD_H1、PROD_H2），每口均穿入储层。PROD/INJ 仅是演示命名，不代表已设置生产/注入控制。

## 导入

1. 在网格导入中选择 `SYNTHETIC.GRDECL`。几何和五项属性在同一个文件中，不需要另外导入 INC 或 INIT。
2. 在井头导入中选择 `Wellheader.txt`。
3. 在井轨迹导入中选择 `wells` 下的六个 `.dev` 文件。井名与井头完全一致，用于按井名汇合。
4. 勾选网格及井；需要时切换 PORO/PERMX 属性，打开网格透视，查看内部井段。

采用未指定 CRS 的局部笛卡尔坐标，X 向东、Y 向北，长度均为米，KB = 0。**为匹配当前网格和井渲染直接使用 Z 的行为，本套轨迹 Z 和 TVD 都以深度向下为正。** `.dev` 为当前读取器支持的具名列文本格式，不采用常见 Petrel 文件的负高程 Z 约定；不要直接与负高程轨迹混用。MD 为相邻轨迹点空间距离的累计值，角度由相邻站段计算。

## 重建与验证

在源码根目录运行 `node tools/generate-demo-data.cjs` 可确定性重建数据，无需外部依赖。文件会覆盖本目录下生成的同名数据，保留 README。

现有测试程序提供 `onSyntheticDemoData` 验证项；将 `IDOS_DEMO_DATA_DIR` 设为本目录绝对路径后运行该项，实际调用网格、井头和井轨迹读取器，检查网格维度与活动数、全部属性长度和值、井名与井口匹配、轨迹点数、测深递增和深度约定。它不会修改工程。
