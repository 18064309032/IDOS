# 工况树设计

确认日期：2026-09-25。

## 新建模拟工况

```text
工况1
├─ 运行设置
├─ 网格
├─ 物性与渗流
├─ 初始状态
├─ 井与开发计划
├─ 输出设置
└─ 汇总结果
```

新建工程不自动创建工况。新建工况只初始化上述分类；没有实际网格，不生成主网格或属性节点。

## 关联实际数据后

网格容器下面按实际网格对象名称展示，每个网格有静态属性、区域划分、动态属性三个分类。
几何数据属于网格对象，不另外创建几何节点。来源文件路径作为对象信息保存，不增加文件层级。

- 静态属性：实际已加载的 PORO、PERMX、PERMY、PERMZ、MULTPV、SIGMAV、MULTX、MULTY、MULTZ 等。
- ACTNUM：网格存在活动标记数组时展示该数组；避免与独立 ACTNUM 属性对象重复展示。当前模型未区分文件读取与默认生成来源，来源标记待导入扩展时补齐。
- 区域划分：SATNUM、ROCKNUM、PVTNUM、EQLNUM、FIPNUM。
- 动态属性：只展示已加载的动态属性对象，不预置压力、饱和度节点。
- 井引用及未匹配的井名：位于井与开发计划。
- 汇总结果：实际加载汇总数据后再增加全场、井组、井及曲线，不与输出请求混淆。

## 交互目标

分类不提供显示复选框。网格的显示控制、双击属性切换着色、动态时间步选择、设置编辑器和汇总曲线展示在对应功能接入时实现；本次不把空分类描述为可编辑的完整功能。
暂不创建视图或其他模型结果节点。

## 当前实现边界

已实现默认分类、case.grid 网格引用及其属性归类、case.well 井引用展示，使用项目对象变化通知刷新。
DATA 导入已接入 OPM EclipseState。存在角点或笛卡尔网格时，会创建主网格对象并导入 COORD、ZCORN、ACTNUM，同时导入当前支持的静态属性和区域划分属性。
动态属性、结果文件、物性表编辑、汇总曲线和三维显示交互仍待后续实现；不能仅凭关键字生成假数据节点。
