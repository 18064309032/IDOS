# IDOS 使用指南

更新日期：2026-10-14。对应 `D:/CMakeCoder/IDOS` 工程。

## 启动与工作区

从当前构建产物目录启动 `bin/Debug/idosd.exe`。界面包含 Ribbon、数据树、工况树、二维/三维视图和底部输出、调试、Python 控制台、助手面板。面板可以停靠或浮动，当前活动视图通过边框区分。

使用新建工程建立当前会话，通过打开、保存及另存为操作单个 .idos 工程文件。工程文件保存实际业务数据及关联，命令撤销历史仅在当前会话中有效；工程设置编辑入口仍未开放。

## 数据导入

| 输入 | 用途 |
|---|---|
| 井头文件 | 建立或合并井及井口信息；当前解析器按包含 wellheader 的文件名识别 |
| Petrel `.dev` | 井轨迹与空间基准 |
| `.las` | 测井曲线 |
| ECLIPSE `.DATA` | 工况、网格、属性及可识别的井控等内容 |
| 支持的 ECLIPSE 网格文件 | 独立网格及属性，以文件对话框列出的格式为准 |
| ECLIPSE 流体/岩石表 `.TXT`、`.DAT`、`.PRN` | 在工况树“流体与岩石属性”组导入；表作为共享数据对象进入数据树 |
| `.UNRST` | 向已有匹配网格导入动态属性及报告步 |

节点右键菜单按节点提供新建、导入和删除操作。数据树空白处没有菜单；工况树保留空白新建/导入入口；渲染视图没有右键菜单。

同井名数据可经导入命令合并。删除、导入等通过平台撤销和重做执行，失败操作不进入历史。格式识别成功不表示已支持行业文件的全部关键词，错误以输出面板具体信息为准。

流体/岩石表文件按 ECLIPSE 关键字段落解析，数值记录以 `/` 结束；目前支持 DENSITY、PVTO、PVDO、PVDG、PVTG、PVZG、PVTW、SWOF、SGOF、SWFN、SGFN、SOF2、SOF3、SLGOF、SGWFN 和 ROCK。导入后，流体表出现在数据树“Fluids”组，岩石函数表出现在“Rock Physics Functions”组；目标工况只保存这些表的引用，并在其“流体与岩石属性”组中展示。导入可撤销和重做；在工况树表节点右键可打开该工况的属性曲线窗口。

## 模型查看

从 Ribbon 新建三维或二维窗口，选择树节点并勾选支持展示的对象。多窗口时确认目标视图，各窗口显示状态独立。

平台启动后，各视图显示悬浮工具条，提供标准视角、坐标轴、旋转、正交投影、光标坐标追踪、视图联动、选择、点缩放、点探针、距离测量、网格透视、缩放视图、缩放至选中对象、适配全部对象、背景颜色、隐藏全部/显示全部和截图；工具条最左侧 10px 把手可按住拖动。数值模拟与视图工具由平台直接提供，不参与插件管理。工具条操作绑定所在视图，Ribbon 操作绑定当前活动视图。标准视角、投影切换及视图联动只适用于三维视图；缩放至选中对象要求目标视图中有可见选中对象。点缩放单击一次模型后自动结束；鼠标跟踪在鼠标移动到模型表面时显示坐标；只有开启选择工具才能在画布中选中对象，关闭工具清除高亮。点探针在点击附近持续显示对象、渲染单元/点编号、坐标和渲染数据已有属性，并标记拾取单元；距离测量依次拾取两个模型点并显示三维直线距离。

动态属性可以选择报告步并自动播放。每个实际报告步变化写入输出面板，便于核对当前显示内容。

## OPM Flow

### 运行环境

Windows 通过 WSL2 调用 Linux Flow。先安装 WSL2、Linux 发行版和 Flow，IDOS 不携带这些离线安装包。用于解析的 opm-common 不等于 Flow 求解器。

默认配置为 `Ubuntu-24.04`、`/usr/bin/flow`、2 个 CPU 线程，可在运行状态窗口修改，保存到用户配置。PowerShell 验证：

```powershell
wsl -l -v
wsl -d Ubuntu-24.04 -- /usr/bin/flow --version
```

### 操作流程

1. 导入 DATA 工况，确认已关联目标网格。DATA 自带网格时不必重复导入，否则导入对应网格并关联。
2. 选择工况并运行预检，处理阻断项。
3. 初始化运行目录，复制 DATA 和关联输入；初始化本身不启动模拟器。
4. 在主页“模拟”分组打开运行状态窗口，确认发行版、程序路径和线程数，启动 Flow。
5. 检查实时输出；正常退出后自动导入本次 UNRST。
6. 选择动态属性，浏览或播放报告步，需要时归档目录或导出清单报告。

每次计算使用独立 `results-<UUID>` 目录，日志为其中的 `flow-console.log`。关闭运行窗口只隐藏界面，停止任务会终止本次 Linux 进程组。工程切换、工程销毁或目标工况/网格删除会取消任务；程序退出时停止任务并清理资源。

手动 UNRST 导入从结果文件窗口或网格动态属性组进入。手动和自动路径共用 `simulation.results.import` 命令，参数为 `gridId`、`filePath`，支持撤销与重做。

### 排查

| 现象 | 检查方向 |
|---|---|
| 找不到发行版或 Flow | 核对运行窗口配置，用 PowerShell 验证 Linux 路径 |
| 预检或初始化失败 | 检查 DATA、INCLUDE 文件和网格关联 |
| 非零退出或没有 UNRST | 查看实时输出和 flow-console.log，确认算例成功计算 |
| 网格不匹配或属性重复 | 核对结果所属输入网格及已导入属性 |
| 插件无法卸载 | 清理运行任务、相关数据和命令历史中的依赖 |

## 本地助手

部署目录 `assistant/local-ai.json` 指定运行程序和 GGUF 模型。当前配置使用 llama-server、Qwen2.5-Coder 7B 量化模型；资源由构建部署，不由界面自动下载。

Enter 发送、Shift+Enter 换行，消息为普通文本“你：内容”“助手：内容”。助手通过注册命令调用功能，并非所有界面操作都已开放。切换工程后旧请求失效，避免旧响应修改新工程。

启动失败时核对配置相对路径、运行程序和模型是否存在，查看输出和调试信息。资源配置见 [开发指南](开发指南.md)。

## 输出与边界

输出面板记录运行、导入、报告步和错误，调试面板提供诊断信息。Python 控制台只有界面，运行按钮禁用；拟合评价和通用分析能力待开发。

## 主页与必需模块

井数据导入已支持井分层、射孔和 Checkshot：从上方数据树的“井”分组或具体井右键“导入数据…”选择文件，按井名合并；多井文件从分组入口导入，指定单井入口拒绝包含多口井的文件。新导入井默认不显示，已有井的身份及工况引用保持不变，修改可撤销、重做，失败文件不部分写入。

井分层支持旧版三列 `Well Horizon MD` 简表（可带第四列类型）及 Petrel `BEGIN HEADER` 格式，使用 Measured Depth，不将 TVD 当成 MD。带空格的井名及层位名用双引号包围。本阶段仅保存井名、层位名和 MD，其他 Petrel 字段及可选类型列尚未进入模型。简表默认深度单位为米，可在记录前声明 `UNITS M` 或 `UNITS FT`。

射孔支持 `Well TOP BOTTOM [OPEN/SHUT]` 简表及 EV `UNITS FIELD/METRIC`、`WELLNAME` 分段的 perforation 事件。深度统一换算为米，未映射网格层号为 0；事件日期保留原文，不进行日期解释或模拟 COMPDAT 映射。当前不解析其他 EV 事件和射孔枪参数。

Checkshot 支持旧版 `TVD TWT Well` 表头及无表头的“深度 时间 井名”三列记录，也支持 OWT/Time 列。可声明 `UNITS M/FT MS/S`；未声明单位或时间类型时保持未知，保留原始数值正负号，按深度排序并保持时间配对。相同深度、时间的重复点合并，冲突点及非单调时间曲线拒绝导入。数据用于查看，当前不进行自动时深转换。

井节点下的分层、射孔和校深分类右键“查看数据…”打开只读数据快照表。

具体井节点和井轨迹节点右键“显示设置…”打开同一个井显示面板，井轨迹入口直接选中轨迹页。面板固定绑定打开时的井和目标视图，提供井口点/球体/圆锥、颜色和大小，轨迹颜色、像素线宽、平滑及测深裁剪，实测射孔颜色与线宽，井名标签和整体不透明度、显隐。点大小使用像素，球体和圆锥大小使用模型坐标单位；裁剪按 MD（米）对轨迹边界插值，不修改原始数据。实测射孔只沿已有轨迹显示，不把模拟 COMPDAT 层号解释为深度。各视图设置独立，局部显示设置不进入撤销历史；井删除、工程切换或视图关闭时关闭面板。

井口默认显示旧版专用井符号，可在“井口”页选择自动或 0～27 编号，列表带符号预览；自动模式优先读取井头文件符号，没有井头时按生产/注入及开关井状态回退。符号覆盖只改变目标视图，不修改井头数据。轨迹页的“管状线效果”默认开启，采用带光照的线条，粗细仍是像素线宽。“状态配色”页提供生产、注入、关闭及停井的井颜色和射孔颜色，可让射孔沿用井色；关闭“按井状态着色”后使用井口、轨迹和射孔各自的单色。实测关闭射孔使用关闭颜色。停井由对应文件/显示符号表达，当前没有独立停井数据字段。

网格和网格属性节点共用“显示设置…”面板：从网格打开时进入“外观”页，从属性打开时进入“着色”页并预选该属性。外观页提供网格显隐、表面/线框/表面加边线/点显示、不透明度、边线颜色和像素线宽。边线开关与表面/表面加边线模式同步；线框模式可调线宽，边线颜色只用于表面边线。高亮临时覆盖边线外观，取消后恢复用户设置；切换属性、报告步或刷新数据保留外观。面板和菜单固定绑定打开时的目标视图，其他视图不受影响。网格或目标视图失效、工程切换时关闭面板，属性删除回退单色。
网格着色从工况树右键菜单进入：网格节点的“着色依据”可以选择单色或属性，网格和属性节点的“显示设置…”共用同一面板。属性节点另有“在目标视图中显示”。面板提供旧工程的 19 种色带及蓝到红、蓝到黄、灰度共 22 种预设，下拉列表显示渐变预览和中文名称，可设置反转、自动/手动范围、单色、无效值颜色及图例开关，修改立即作用于打开入口时的目标视图，各视图独立。手动范围要求最小值小于最大值；自动范围只统计当前报告步的有效且有限的活动单元值。缺失或非有限数值使用无效值颜色。当前不提供分类属性的离散色带、单位补全及跨报告步统一自动范围。

主页顺序为“工程、窗口、模拟、结果、输出、扩展”。数值模拟由平台内置提供，不依赖独立插件 DLL。专业插件继续保留独立业务页面。

工况新建和导入使用工况树。主页模拟分组提供 Deck、摘要、预检、初始化、运行状态/启动、停止和工作流；结果分组提供数据查看、结果文件、报告步播放和曲线分析；输出分组提供 DATA 导出、运行归档和报告，保留截图及图片导出。视图复位、图例等操作统一由各视图的悬浮工具条提供。


### 网格筛选

在具体网格节点右键选择“网格筛选…”，打开独立的 `IDOSGridFilterWidget`。显示设置仍只包含外观和着色。

- “网格筛选”页提供 I/J/K 三列；可以启用范围、逐项勾选，或按“间隔”选择。每列的范围和勾选项取并集，三列按选择的并集或交集组合。隐藏与反选都保留不满足条件的活跃单元。
- “属性筛选”页左侧搜索并勾选属性，右侧编辑每个属性的范围、七种比较方式、边界包含、无效值和容差。属性条件按任一或全部组合，可指定显示属性；属性操作与网格操作分别计算，再取交集。小于比较使用最大值，等于比较使用最小值及容差。
- 范围条支持拖动两端手柄；直方图显示活跃单元的数据分布和命中部分，摘要显示匹配数与目标视图当前显示数。动态属性跟随当前报告步。改变条件不会自动应用，点击“应用筛选”更新打开窗口时的目标视图。
- 顶部可选择临时筛选或本网格的已保存筛选；“保存筛选”更新当前结果，“另存为新对象…”创建结果。结果位于“网格 → 筛选”下，支持独立勾选、编辑、显示设置、重命名和删除。创建、更新、重命名和删除支持撤销／重做；删除来源网格同时删除其筛选，撤销恢复。
- 筛选只保存来源和条件，不复制网格几何。启用条件中的属性缺失时结果失效，保留条件供恢复或编辑；局部预览及外观不修改源数据。“保存筛选”先更新工程内的筛选对象，再保存 .idos 工程文件即可持久化。

保存临时预览为结果后，取消该结果节点的勾选会清除对应的主网格预览，恢复完整活跃网格，并保留主网格着色和外观。若之后重新应用了另一组临时条件，取消旧结果不会清除新的预览。

## 数据对象的复制、粘贴、移动与重命名

数据、工况、网格和属性节点使用“复制／剪切／粘贴”操作对象本身。Ctrl+C、Ctrl+V 创建新 ID 的独立副本；同类数据可粘贴到数据树对应分类，工况可粘贴到工况树空白或工况根节点。工况副本复制其关联数据、网格及其属性和筛选，重映射对象、筛选属性和工况关系的 ID，并清空运行状态和输出目录。运行记录不继承。

在井或流体／岩石表的数据节点上右键“添加到工况…”，选择目标工况，关联已有数据。支持多选；此操作不复制源数据。它与复制粘贴是两个独立功能。

拖动默认复制，Ctrl 拖动同样复制，Shift 拖动或 Ctrl+X／Ctrl+V 在允许的目标之间移动。网格在工况之间移动；属性在尺寸一致的网格之间移动。被筛选使用的属性禁止跨网格移动，可复制。剪切时不删除源对象，粘贴成功后才改变归属。复制、移动和重命名支持撤销／重做。

工况本身及数据树顶层对象已归属当前工程，没有其他同级容器，因此不开放剪切移动；可复制、拖动复制和重命名，不支持随意改变固定分类或排序。网格属性可粘贴到网格根、兼容属性分组或属性节点；属性维度不兼容时不接受。

跨工程、外部文件拖入及井内曲线等部件的独立操作尚未开放。筛选随整个网格复制时重映射属性 ID，单独跨网格复制筛选不开放。

## 工程文件保存与恢复

“打开工程”“保存工程”“工程另存为”使用单个二进制 .idos 文件，快捷键为 Ctrl+O、Ctrl+S 和 Ctrl+Shift+S。工程文件底层采用 HDF5，包含工程名称、坐标和单位偏好、对象 ID／名称／类型、业务字段、实际数值数组以及工况和容器关系。井、网格、静态与动态属性、筛选、流体／岩石表、地震、微地震、压裂、天然裂缝、地层面、边界和生产历史均保存解析后的数据；来源路径只作记录，恢复数据不重新读取原始文件。

保存成功后清除未保存标记。业务数据、名称或工程信息变化后标题出现修改标记；新建、打开另一个工程或关闭窗口时，可选择保存、放弃或取消。打开时先在临时工程中恢复并校验全部对象和关系，成功后才切换当前工程；保存失败不替换已有工程文件。撤销历史不写入文件。

工程保存业务数据、当前选择和 UI 工作现场：2D/3D 视图、活动视图、相机及主页相机、相机联动、背景、坐标轴、图例、光标跟踪、视图工具栏、各视图独立显隐与不透明度、井显示设置、网格外观和着色及属性关联、筛选预览、地震切片、测井曲线通道与深度范围、树展开与多选。窗口位置和尺寸、停靠面板布局、最近工程使用本机 QSettings，不随工程跨机器传播。没有 UI 状态的旧工程按默认视图打开。显示操作不进入业务撤销历史，但会使工程需要保存；本机窗口位置变化不标记业务工程修改。工程设置编辑入口仍未开放。工程文件是 IDOS 自定义 HDF5 结构，当前没有提供标准 VTKHDF／ParaView 导出。

工程保存采用版本 2 的紧凑二进制 HDF5 布局，仍可打开版本 1 工程。旧工程第一次打开仍受原布局影响，保存或另存为后使用新版布局；需要保留旧文件时请使用另存为。旧版程序不能读取版本 2。当前读写同步执行，大工程期间界面仍可能等待。
