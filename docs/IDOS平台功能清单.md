# IDOS 平台功能完整清单

> 文档版本：v1.0
> 创建日期：2026-09-22
> 状态：待评审

---

## 一、定位

```
IDOS = 油藏行业的通用 3D 可视化平台

核心用户：油藏工程师
核心场景：数据分析 → 可视化 → 汇报

类比：
• QGIS = 地理信息的通用平台
• IDOS = 油藏数据的通用平台

平台 = 基础框架（你开发）
插件 = 业务功能（别人开发）
```

---

## 二、功能总览

| 层级 | 模块 | 说明 |
|------|------|------|
| **第一层** | 数据管理 | 工程、对象、导入导出 |
| **第二层** | 可视化 | 3D、2D、图表 |
| **第三层** | 交互 | 工具、选择、编辑 |
| **第四层** | 平台扩展 | 插件、API、事件 |
| **第五层** | 工具 | 撤销、帮助、设置 |

## 五、接口设计要求

### 5.1 核心接口

```cpp
// 工程接口
interface IProject {
    string name
    string filePath
    bool isDirty
    IObjectStore objects
}

// 对象存储接口
interface IObjectStore {
    void add(IObject obj)
    void remove(string id)
    IObject find(string id)
    IObject findByType(string type)
    IObject findByName(string name)
}

// 对象接口
interface IObject {
    string id
    string name
    string type
    IProperty[] properties
    IGeometry geometry
}
```

### 5.2 扩展点接口

```cpp
// 数据导入扩展点
interface IDataImporter {
    bool canImport(string path)
    IObject import(string path)
    IImporterMetadata metadata
}

// 渲染器扩展点
interface IRenderer {
    void render(IObject obj, IRenderContext context)
    void updateStyle(IStyle style)
}

// 工具扩展点
interface ITool {
    void onActivate()
    void onDeactivate()
    void onMousePress(IMouseEvent event)
    void onMouseMove(IMouseEvent event)
    void onMouseRelease(IMouseEvent event)
}
```
