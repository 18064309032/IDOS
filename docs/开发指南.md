## 准备

阅读 [AGENTS.md](../AGENTS.md)、[架构设计](IDOS架构设计.md)、[源码目录](IDOS源码目录.md)和[工作进度](工作进度-CJW.md)。固定目录决定类归属，功能状态以进度摘要为准；历史记录不代表当前仍保留旧接口。

当前使用 Windows x64、MSVC、Qt 5.15.2、C++17。预设采用 version 4，建议 CMake 3.23 或更高；根脚本声明 3.16，但实际还使用更高版本命令，不承诺旧版本完整兼容。

准备 `thirdparty/` 预编译依赖、Qt Core/Gui/Widgets/Network/LinguistTools，以及测试需要的 Test。助手运行程序、配置和模型也是当前构建的部署输入。

## 构建

唯一构建目录为 `E:/CJW-Archive/IDOS-Build/win-x64-debug-local`。从仓库根目录运行：

```powershell
cmake -S . -B E:/CJW-Archive/IDOS-Build/win-x64-debug-local `
    -G "Visual Studio 17 2022" -A x64 `
    -DIDOS_QT_DIR="D:/Qt/Qt5.15.2/5.15.2/msvc2019_64" `
    -DIDOS_BUILD_TESTS=ON -DIDOS_ENABLE_RENDER=ON
cmake --build E:/CJW-Archive/IDOS-Build/win-x64-debug-local --config Debug --parallel 6
```

本地预设可参考 `CMakeUserPresets.example.json`，配置时显式指定 `-B E:/CJW-Archive/IDOS-Build/win-x64-debug-local`。禁止源码内构建；运行和验证均使用该目录的最新产物。

程序和平台 DLL 在 `bin/Debug/`，插件在其 `plugins/`，翻译在 `i18n/`，模型资源在 `assistant/`。Debug 为 `idosd.exe`，Release 为 `idos.exe`；Release 也在同一构建目录用 `--config Release` 构建，最近验收记录针对 Debug。

运行进程占用 DLL 时先关闭对应程序再替换。构建不提供 WSL 或 Flow 安装环境。`IDOS_ENABLE_RENDER=OFF` 目前不是已验证的独立无渲染模式。

## 验证

```powershell
cmake --build E:/CJW-Archive/IDOS-Build/win-x64-debug-local --config Debug `
    --target idos_render_header_checks check_includes --parallel 6
ctest --test-dir E:/CJW-Archive/IDOS-Build/win-x64-debug-local -C Debug --output-on-failure
git diff --check
```

| 测试 | 覆盖 |
|---|---|
| check_includes / check_includes_regressions | 模块边界、公共头归属及检查器回归 |
| command_registry | 命令注册、验证、执行与历史 |
| assistant_widget | 助手请求、命令及工程切换 |
| project_dialog | 工程对话框与主窗口 |
| well_import / well_path | 井头、轨迹、LAS 合并及空间基准 |
| case_workflow | DATA、渲染、插件及模拟运行 |
| tree_incremental | 树同步、菜单、工具装配、窗口隔离和事件生命周期 |

变更目标重新编译后再测试，避免旧二进制造成误判。按风险选择验证；文档修改检查链接和事实，不需要重复完整构建。

实际 Flow 用例由 `IDOS_FLOW_SMOKE_DATA` 启用，指向准备好的 SPE1 DATA 及完整 INCLUDE 包。未设置时对应用例跳过；普通测试不能隐式依赖个人环境或外网。

## 翻译与资源

源文本使用英文 `tr()`，中文写入 TS，不翻译内部标识、协议字段和文件路径。

```powershell
cmake --build E:/CJW-Archive/IDOS-Build/win-x64-debug-local --config Debug --target lupdate
cmake --build E:/CJW-Archive/IDOS-Build/win-x64-debug-local --config Debug --target translations
```

平台扫描到 `i18n/idos_zh_CN.ts`，插件使用独立 TS，由各插件 CMake 管理编译和部署。平台 lupdate 不代表插件翻译已更新；部署最新 QM 后验证中文。

`resources/assistant/local-ai.json` 定义相对于助手目录的 runtime、model 和启动参数，当前配置为 Vulkan 后端。更换模型或后端需核对实际资源；CMake 当前部署固定模型文件，资源缺失可能导致部署失败。

Flow 与 opm-common 是独立依赖，前者通过 WSL 运行，后者用于解析；流程见 [使用指南](使用指南.md)。

## 扩展与贡献

具体数据、Provider、Metadata、命令及工具放在 App 对应业务目录或插件；通用框架放在所属模块根部，不增加未确认目录或类。插件只使用公共入口，不链接 App 内部实现。参见 [插件开发](../src/plugins/README.md)。

视图工具覆盖 `IDOSTool::onEventFilter()` 处理 Qt 输入，使用 `observeVtkEvent()` 的 VTK 成员函数监听，覆盖 `onVtkEvent()` 处理状态。不使用友元、手写静态回调、SLOT 连接或额外事件分发框架。

提交说明问题、最终行为和实际验证，同步翻译与工作进度。不要将局部回归描述为全量验收，不以关闭新警告替代根因处理。完整代码规范以 AGENTS.md 为准。
