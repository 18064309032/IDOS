## 一、主页（开始）

### 1.1 项目管理

| 功能 | 说明 |
|------|------|
| 新建项目 | 创建空白项目，设置项目名称、路径、单位制 |
| 打开项目 | 打开 .idos 项目文件，加载所有数据 |
| 保存 | 保存当前项目状态 |
| 另存为 | 另存为新项目文件 |
| 最近项目 | 显示最近10个项目，可快速打开 |
| 项目属性 | 查看/修改项目基本信息 |

### 1.2 系统设置

| 功能 | 说明 |
|------|------|
| 常规设置 | 主题、语言、界面缩放 |
| 单位设置 | 长度、温度、压力、渗透率等单位制 |
| 路径设置 | 默认数据路径、导出路径 |
| 快捷键设置 | 自定义键盘快捷键 |
| 渲染设置 | 显卡选择、抗锯齿、显存限制 |
| AI设置 | API配置、模型选择 |

### 1.3 帮助

| 功能 | 说明 |
|------|------|

| 教程 | 新手入门视频教程 |
